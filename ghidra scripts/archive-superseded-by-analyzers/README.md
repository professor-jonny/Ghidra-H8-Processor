# Archived scripts

These scripts were written to resolve table-helper call sites, add the references and
annotate the batch-2 tables by hand. The H8 ECU Table Access Analyzer
(H8EcuTableAnalyzer) now does that on every analysis run (bookmarks, and references with
"Write references" on), with the helper addresses as options. They are kept here, with
their git history, in case one is needed for a ROM the analyzer does not handle.
Move one back to ghidra scripts/working to use it again.
