## Conventions
- Ghidra address = XML address (no offset when reading in Ghidra). 2D header = 4 bytes before data, 3D header = 7 bytes, 1D scalars have no header.
- Axis record: 6 byte header (out ptr, in ptr, count) then big-endian 16-bit words.
- Raw axis entries are named AXIS_<DATA ADDR>_<N>x16 so the Ghidra importer (h8539_import_tables_xml2.py) gets the length from the name. They are 2D tables with a static Index axis so EcuFlash shows them as a row. Category "Axis Tables - <input variable>"; known inputs scaled (F170 RPM, F13E TPS Percent, F13A BatteryVoltage, F1E0 Airflow Hz), others uint16.
- The importer labels 1D entries by name only and skips addresses that already have a label. Old SCALING_TABLE_ labels in Ghidra may need the "clear scraped" option before the next import. The 2D branch expects a 4 byte header, so the AXIS_ entries (6 byte header) may be flagged suspect. Not yet run.
